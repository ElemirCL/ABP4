* Proyecto de lista de Tarea - Módulo 4

En este proyecto nos enfocamos en realizar un programa web donde se pueda generar una `lista de tareas` y a la vez se pueda `modificar`.
Cuenta con una interfaz simple donde nos encontramos con un `input` donde se debe ingresar la descripción de la tarea que deseamos guardar.
Luego debemos hacer click en el botón que se encuentra a la derecha del input para así `agregarla a la lista de tareas`.
Una vez agregada la Tarea a la lista se pueden realizar 3 acciones.

* **Modificar Descripción: Nos permite `cambiar la descripción` de la tarea guardada en la lista.

* **Completar Tarea: cada Tarea agregada a la lista cuenta con un `checkbox` que nos ayudara a tener visibilidad de las tareas que ya hemos terminado.

* **Eliminar Tarea: nos permite `eliminar` la tarea que deseemos.
